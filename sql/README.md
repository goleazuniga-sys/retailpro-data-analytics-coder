# Scripts SQL - RetailPro

Esta carpeta centraliza los scripts SQL del proyecto RetailPro según la estructura solicitada en las consignas de los módulos.

## Archivos

- `m3_ventas_tech_db.sql` — creación de la base de datos, tablas y carga inicial.
- `m4_consultas_negocio.sql` — métricas y consultas agregadas de negocio.
- `m5_consultas_joins.sql` — consultas con INNER JOIN, LEFT JOIN, UNION ALL y GROUP BY.

Los mismos archivos se mantienen también dentro de sus respectivos módulos para conservar la documentación y trazabilidad del proyecto.
